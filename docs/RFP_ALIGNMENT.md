## 2. 3대 핵심 모듈

1. **기초노동질서 자율점검 (문서)** — 근로계약서·임금명세서·취업규칙 분석
2. **산재위험 자율점검 (사진)** — 사업장 환경 → 위험요소·등급화
3. **노동문서 특화 VLM OCR** — 한국어 노동문서 인식 모델 파인튜닝

## 3. 데이터·LLM 처리 분리 (가장 중요한 원칙)

| 처리 단계 | 위치 | 데이터 |
|---|---|---|
| OCR (VLM) | 온프레미스 GPU | 개인정보 포함 원본 |
| 개인정보 검출·제거 | 온프레미스 LLM | 개인정보 포함 원본 |
| 가드레일 | 온프레미스 LLM | 비식별화 텍스트 |
| **법적 판단** (비계산적) | **외부 상용 LLM API** | **비식별 텍스트 + 지식데이터** |
| 로직 계산 (계산적) | 백엔드 모듈 | OCR 추출값 (사용자 수정 후) |
| 산재 사진 분석 | 외부 상용 LLM API | 사업장 환경 사진 |

### 데이터 생명주기
- 업로드 원본 → 분석 완료 즉시 삭제
- 비식별 OCR 결과 → 학습용 보존, 학습 완료 후 삭제
- 행정제재 목적 활용 금지
