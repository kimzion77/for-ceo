## 사전 준비

### 시스템 요구사항
- Python **3.11+** (현재 3.14 검증됨)
- Node.js **18+**
- Git Bash 또는 WSL (Windows 한국어 경로 지원)

### Secrets

`backend/.streamlit/secrets.toml`:
```toml
api_key = "..."              # 일반 API 키 — BFF·검토앱이 사용
admin_api_key = "..."        # 관리자 전용 — 슬롯편집·캐시관리
admin_password = "..."       # Streamlit 로그인
openai_api_key = "..."       # LLM 호출
```

`frontend/.env.local`:
```bash
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8503
CGR_API_KEY=<backend/.streamlit/secrets.toml의 api_key 와 동일>
CGR_ADMIN_API_KEY=<admin_api_key>
```

## 로컬 실행 (3 서버)

### 1) Python 의존성 설치
```bash
cd backend
pip install -r requirements.txt
```

### 2) Node 의존성
```bash
cd frontend
npm install
```

### 3) 마스터 DB 시드 (최초 1회 + 스키마 변경 시)
```bash
cd backend
python scripts/seed_master_db.py --drop-first
```
- `--drop-first` — 모든 테이블 drop 후 재생성. **audit 데이터도 사라짐** 주의.
- 옵션 없이 실행하면 UPSERT 만 적용 (기존 검토 이력 보존).

기대 출력:
```
[1/7] schema
[2/7] document_type
[3/7] topic + topic_section (corpus)
  topics: 31, sections: 1769
[4/7] check_item from slot YAML
  EC: 35, WR: 115, WS: 11
[5/7] 33-mapping (EC)
  mapping links — topic: 72, law: 41
[6/7] wage statement topic/law links
[7/7] wage masters
  minimum_wage: 5, wage_items: 19, violations: 10, recommendations: 10

=== final counts ===
  check_item: 161 / topic_section: 1779 / law_article: 56 / ...
```

### 4) 3 서버 띄우기

각각 다른 터미널에서:

```bash
# 백엔드 API (port 8503) — Swagger: http://127.0.0.1:8503/docs
cd backend && python launch_api.py

# 관리자 (port 8502) — 로그인: admin_password
cd backend && python launch_admin.py

# 프론트엔드 (port 3000)
cd frontend && npm run dev
```

### 5) 헬스 체크
```bash
curl http://127.0.0.1:8503/health      # API 상태
curl http://127.0.0.1:8502/_stcore/health  # Streamlit
curl http://127.0.0.1:3000/            # Next.js
```

## 트러블슈팅

### 폰트 깨짐 (한글)
- 원인: Pretendard CDN 차단·지연
- 확인: 브라우저 개발자도구 → Network → `pretendardvariable` 200 OK?
- 해결: `app/layout.tsx` 의 `<link>` 가 preconnect 와 함께 로드되는지. 시스템 폴백 (`Apple SD Gothic`, `Malgun Gothic`) 도 활성.

### 백엔드 시작 실패 — "port 8503 in use"
```bash
# Windows
netstat -ano | grep :8503 | grep LISTENING
taskkill //F //PID <pid>
```
또는 다른 포트로:
```bash
uvicorn cgr.api.main:app --port 8513
```

### Streamlit 8502 로그인 안 됨
- `backend/.streamlit/secrets.toml` 의 `admin_password` 확인
- 또는 환경변수 `ADMIN_PASSWORD` 설정

### 폴더명 한국어로 인한 인코딩 에러
- Windows: `PYTHONIOENCODING=utf-8` 환경변수 설정
- `launch_*.py` 가 이미 자동 설정.

### 슬롯 코드가 결과 페이지에 노출됨 (예: "(SLOT_WS_11_사용자_정보)")
- 원인: 이전 LLM 캐시
- 해결: 자동 — `cgr/ws/services/analyze.py` 의 `_strip_slot_codes` 가 post-process.
- 강제: 캐시 비우기 → 재실행

### Next.js dev 컴파일 캐시 손상 — "Cannot find module './xxx.js'"
```bash

npm run dev
```

### `master.db` 깨짐
시드 재실행:
```bash

```

## 신규 기능 추가 — 워크플로

### 새 API 엔드포인트
1. `cgr/<domain>/services/<feature>.py` — 비즈니스 로직
2. `cgr/api/routes/<domain>.py` — 라우터 등록
3. (필요시) `cgr/db/schema.sql` 에 테이블 추가 → 시드 스크립트 갱신
4. `frontend/src/lib/api/<domain>.ts` — 클라이언트 함수
5. `docs/04_자료사전.md` 갱신

### 새 결정성 보장 LLM 호출
```python
from cgr import llm_cache
cache_key = llm_cache.make_key(
    system=sys_prompt,
    user=user_prompt,
    schema={"kind": "my_feature"},
    model=model_name,
)
cached = llm_cache.get(cache_key)
if cached:
    return cached["result"]

# ... LLM 호출 ...

llm_cache.put(cache_key, {"result": data})
```

### 새 룰 (계산형 위반) 추가
1. `backend/scripts/seed_wage_masters.py` 의 `VIOLATION_TYPE_ROWS` 에 `V0XX` 행 추가
2. `cgr/ws/services/rule_engine.py` 에 `rule_v0xx_*` 함수 추가
3. `_RULES` 리스트에 등록
4. (선택) `recommendation_mapping` 에 권고 템플릿 추가
5. 시드 재실행

## 배포 (참고)

현재는 로컬 개발 단계. 운영 시 고려:

### 옵션 A — 단일 호스트
- nginx → Next.js (3000) + FastAPI (8503) + Streamlit (8502)
- SQLite 그대로
- LLM 키는 환경변수

### 옵션 B — 컨테이너
- `frontend/` Dockerfile (Next.js standalone)
- `backend/` Dockerfile (uvicorn + 가져온 Streamlit)
- `master.db` 는 볼륨 마운트
- `llm_cache/` 도 볼륨

### 옵션 C — 멀티 인스턴스
- SQLite → Postgres 전환 (스키마 호환)
- `llm_cache` → Redis
- 부하 분산 시 캐시 일관성 필요

## 코드 컨벤션

- Python: PEP 8 + 한국어 docstring 권장
- TypeScript: strict mode, no `any` 가급적
- 커밋: `[phase-N]` prefix 권장 (예: `[phase-5] WS 페이지 캐러셀 이식`)
- 시간 기준: KST. SQLite는 UTC 저장 (`datetime('now')`) — UI에서 변환
