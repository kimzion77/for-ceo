## 2. 2026 변경 상세

### 제32조 — 노동절 명칭 변경

```yaml
SLOT_노동절_명칭_2026:
  comparator: interpret
  required: false
  master_value: false
  interpret_criteria: |
    - 본문에 "노동절" 표현 → verdict=OK
    - 본문에 "근로자의 날"만 있음 → verdict=VIOLATION (구법 잔존)
    - 5월 1일 유급휴일 조항 자체 없음 → verdict=OK (해당사항 없음)
  violation_severity: LOW
```

**비스코스 검토 사례**: 본문이 "근로자의 날"로 표기 → **🟡 주의** (시정 권장)

### 제69조 — 재심결과 통보 의무 신설

```yaml
SLOT_재심절차_결과통보의무_2026:
  comparator: embed_match
  required: false
  master_value: true
  search_phrases:
    - "재심을 위한 회의를 개최하고 그 결과를 통보"
    - "재심 결과를 통보"
    - "재심 결과를 신청자에게 통보"
  violation_severity: LOW
```

**의미**: 2026 표준은 재심 회의 후 결과를 신청자에게 통보 의무화. 구법은 회의 개최만 명시.

- "채용 시의 교육"           # 구법 (호환)

→ 2026 신법·2025 구법 표현 모두 인식 (호환성 확보).
