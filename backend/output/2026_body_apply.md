```

- 2025:
```

## 제81조 (직장 내 괴롭힘 사실의 확인 및 조치)

**갱신요약:** 피해근로자의 의견 → 피해사원등의 의견

### D 갱신
- 2025:
```
사용자는 직장 내 괴롭힘이 인정된 경우 지체 없이 행위자에 대하여 징계, 근무장소의 변경 등 필요한 조치를 한다. 이 경우 사용자는 징계 등의 조치를 하기 전에 그 조치에 대하여 피해근로자의 의견을 듣는다.
```
- 2026:
```
사용자는 직장 내 괴롭힘이 인정된 경우 지체 없이 행위자에 대하여 징계, 근무장소의 변경 등 필요한 조치를 한다. 이 경우 사용자는 징계 등의 조치를 하기 전에 그 조치에 대하여 피해사원등의 의견을 듣는다.
```

**K(갱신사항) 기존값 보존**: 
```
괴롭힘 인정 시 행위자에 대한 징계·근무장소 변경 등 필요한 조치 의무 — 위반 시 500만원 이하 과태료 (§76조의3 제5항)
```

**K(갱신사항) 최종값**:
```
괴롭힘 인정 시 행위자에 대한 징계·근무장소 변경 등 필요한 조치 의무 — 위반 시 500만원 이하 과태료 (§76조의3 제5항)

— 2026 갱신 —
피해근로자의 의견 → 피해사원등의 의견
```

**L(구법) 기존값 보존**:
```
권고 수준
```

## 제89조 (안전보건 교육)

**갱신요약:** 교육 명칭 정비: '채용 시의 교육'·'작업내용 변경 시의 교육'·'유해위험 작업에 사용 시 특별안전 교육' → '채용 시 교육'·'작업내용 변경 시 교육'·'유해·위험 작업에 필요한 특별교육'

### D 갱신
- 2025:
```
회사는 사원의 산업재해 예방을 위하여 안전 및 보건에 관한 정기교육, 채용 시의 교육, 작업내용 변경 시의 교육, 유해위험 작업에 사용 시 특별안전 교육 등 산업안전보건법령에 따른 제반 교육을 실시하며 사원은 이 교육에 성실하게 참여하여야 한다.
```
- 2026:
```
회사는 사원의 산업재해 예방을 위하여 안전 및 보건에 관한 정기교육, 채용 시 교육, 작업내용 변경 시 교육, 유해·위험 작업에 필요한 특별교육 등 산업안전보건법령에 따른 제반 교육을 실시하며 사원은 이 교육에 성실하게 참여하여야 한다.
```
